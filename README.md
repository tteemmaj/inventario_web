# Sistema de Gestión · Ventanas de PVC ALVIDE (Versión Web) — Cuarto Ciclo, Sección B (Ciclo 2026)

Este repositorio es solo una extensión web del proyecto principal de escritorio. La aplicación de escritorio original la puedes encontrar y clonar desde aquí:
🔗 [GestorInventario (Escritorio)](https://github.com/Jorge-Orozco502/GestorInventario.git)

Para que el sistema funcione correctamente, tanto la aplicación de escritorio como esta versión web deben conectarse a la misma base de datos en la nube alojada en **Aiven** (es necesario configurar la conexión en la aplicación de escritorio para que apunte a Aiven, modificando la clase conexionBD).

## Consideraciones importantes

* Los archivos `.env` y el certificado `ca.pem` son obligatorios y deben ser personalizados con las credenciales propias de conexión para que el servidor inicie sin errores.
